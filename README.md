## 🛍️ex-mark1 E-Commerce API

**ex-mark1** is a modular, minimalist, and high-performance backend API designed for full-stack e-commerce applications. It covers core domains like authentication, product catalog, cart, orders, payments, notifications, and user management with strong schema validation using **Zod** and auto-generated OpenAPI documentation.

The API is architected with precision and security-first principles, leveraging **Express**, **TypeScript**, and advanced validation/middleware patterns for robustness and scalability.

## 🚀 Getting Started

### ☑️ Prerequisites

Ensure you have installed:

- **Node.js** (v18+ recommended)
- **Bun**, **Yarn** or **npm**

### ⚙️ Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/TheDarkArtist/ex-mark1.git
   ```

2. Navigate into the project directory:

   ```sh
   cd ex-mark1
   ```

3. Install dependencies:

   ```sh
   yarn install
   # or
   npm install
   ```

4. Copy and configure environment variables:

   ```sh
   cp .env-example .env
   # Edit .env with your settings
   ```

5. Start the development server:

   ```sh
   yarn dev
   # or
   npm run dev
   ```

> The API will be available at [http://localhost:5000](http://localhost:5000)

---

## 📚 API Documentation

- OpenAPI docs served at: `http://localhost:5000/api/docs`
- Raw OpenAPI JSON available at: `http://localhost:5000/api/openapi.json`
